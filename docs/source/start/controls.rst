Controls and Keybindings
======================

Currently, there is no functionality for modifying the keybindings.

.. Note::
   Changing the names of :ref:`mark groups <groups>` and :ref:`image categories <categories>` will change their name in the Controls window of Image Marker to help keep track of which mark group and category corresponds to which buttons.

Keybindings
-----------

Below is a table of the keybindings, with MacOS and Windows/Linux listed in separate columns.

.. list-table::
   :widths: 34 33 33
   :header-rows: 1

   * - Action
     - MacOS
     - Windows/Linux
   * - Group "1" - "9"
     - :kbd:`1` - :kbd:`9` (also :kbd:`trackpadClick`, default group 1)
     - :kbd:`1` - :kbd:`9` (also :kbd:`LeftMouseButton`, default group 1)
   * - Category "1" - "5"
     - :kbd:`Cmd` + :kbd:`1` - :kbd:`5`
     - :kbd:`Ctrl` + :kbd:`1` - :kbd:`5`
   * - Next
     - :kbd:`Tab`
     - :kbd:`Tab`
   * - Back
     - :kbd:`Shift` + :kbd:`Tab`
     - :kbd:`Shift` + :kbd:`Tab`
   * - Change frame
     - :kbd:`Space`
     - :kbd:`Space`
   * - Delete mark
     - :kbd:`Shift` + :kbd:`trackpadClick` on mark
     - :kbd:`Shift` + :kbd:`LeftMouseButton` on mark
   * - Delete selected marks
     - :kbd:`Delete`
     - :kbd:`Delete`
   * - Undo mark
     - :kbd:`Cmd` + :kbd:`Z`
     - :kbd:`Ctrl` + :kbd:`Z`
   * - Redo mark
     - :kbd:`Cmd` + :kbd:`Shift` + :kbd:`Z`
     - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`Z`
   * - Enter comment
     - :kbd:`Enter`
     - :kbd:`Enter`
   * - Focus
     - :kbd:`Option` + :kbd:`trackpadClick`
     - :kbd:`MiddleMouseButton`
   * - Zoom in/out
     - :kbd:`TwoFingerScroll`
     - :kbd:`Wheel`
   * - Favorite image
     - :kbd:`F`
     - :kbd:`F`
   * - Open Save...
     - :kbd:`Cmd` + :kbd:`O`
     - :kbd:`Ctrl` + :kbd:`O`
   * - Open Images...
     - :kbd:`Cmd` + :kbd:`Shift` + :kbd:`I`
     - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`I`
   * - Import Mark File...
     - :kbd:`Cmd` + :kbd:`Shift` + :kbd:`M`
     - :kbd:`Ctrl` + :kbd:`Shift` + :kbd:`M`
   * - Settings
     - :kbd:`Cmd` + :kbd:`,`
     - :kbd:`Ctrl` + :kbd:`,`
   * - Zoom In
     - :kbd:`Cmd` + :kbd:`=`
     - :kbd:`Ctrl` + :kbd:`=`
   * - Zoom Out
     - :kbd:`Cmd` + :kbd:`-`
     - :kbd:`Ctrl` + :kbd:`-`
   * - Zoom to Fit
     - :kbd:`Cmd` + :kbd:`0`
     - :kbd:`Ctrl` + :kbd:`0`
   * - Copy selected mark coordinates
     - :kbd:`Cmd` + :kbd:`C`
     - :kbd:`Ctrl` + :kbd:`C`
   * - Frames slider in multiframe images
     - :kbd:`Cmd` + :kbd:`F`
     - :kbd:`Ctrl` + :kbd:`F`
   * - Show/Hide Marks
     - :kbd:`Option` + :kbd:`M`
     - :kbd:`Alt` + :kbd:`M`
   * - Show/Hide Mark Labels
     - :kbd:`Option` + :kbd:`L`
     - :kbd:`Alt` + :kbd:`L`
   * - Show/Hide Imported Mark Catalogs (up to 9)
     - :kbd:`Option` + :kbd:`1` - :kbd:`9`
     - :kbd:`Alt` + :kbd:`1` - :kbd:`9`
   * - Gaussian Blur...
     - :kbd:`Cmd` + :kbd:`B`
     - :kbd:`Ctrl` + :kbd:`B`
   * - Controls
     - :kbd:`Cmd` + :kbd:`/` or :kbd:`F1`
     - :kbd:`F1`
